I'm a developer in training — part self-taught, part formal education — with a strong focus on **backend development** and a growing interest in **full-stack**, **systems**, **networking**, and **cybersecurity**.

I learn by building real things. My path goes from writing application code to understanding the infrastructure it runs on.
